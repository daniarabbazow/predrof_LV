# Лабораторная работа № 2. Калькулятор на Qt

Калькулятор с двумя режимами — обычным и инженерным. Режим выбирается радиокнопками,
окно при этом само перестраивается и меняет ширину.

## 1. Установка Qt (Windows, один раз)

Qt ставится через MSYS2 — тот же, через который установлен компилятор `g++`.
Если MSYS2 ещё нет, скачайте установщик с https://www.msys2.org и установите в `C:\msys64`.

1. В меню «Пуск» откройте **MSYS2 UCRT64**.
2. Обновите MSYS2:
   ```
   pacman -Syu
   ```
   Если окно попросит закрыться — закройте, откройте **MSYS2 UCRT64** снова
   и ещё раз выполните `pacman -Syu`.
3. Установите Qt, Qt Creator, CMake и Ninja:
   ```
   pacman -S mingw-w64-ucrt-x86_64-qt6-base mingw-w64-ucrt-x86_64-qt-creator mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-ninja
   ```
   На вопрос `Proceed with installation? [Y/n]` ответьте `Y`. Скачивается много, это может занять время.
4. Убедитесь, что в переменной PATH есть `C:\msys64\ucrt64\bin` (её добавляли для `g++`).
   После изменения PATH перезапустите терминал или VS Code.
5. Проверьте в новом терминале:
   ```
   cmake --version
   ninja --version
   ```

## 2. Сборка и запуск из терминала

В папке проекта (там, где лежит `CMakeLists.txt`):

```
cmake -S . -B build -G Ninja
cmake --build build
.\build\calculator.exe
```

Первая команда настраивает проект (её достаточно выполнить один раз), вторая собирает,
третья запускает. После изменений в коде повторяйте вторую и третью.

## 3. Qt Creator (по желанию)

Qt Creator — среда разработки для Qt: в ней удобнее редактировать код и запускать программу кнопкой.

1. Запустите его командой `qtcreator` в терминале.
2. **File → Open File or Project** → выберите `CMakeLists.txt` из папки проекта.
3. Нажмите **Configure Project**, затем зелёную кнопку ▶ (Run) слева внизу.

Если Qt Creator пишет, что не найден комплект (Kit), добавьте Qt вручную:
**Edit → Preferences → Kits → Qt Versions → Add** и выберите файл `qmake6.exe`
(или `qmake.exe`) из папки `C:\msys64\ucrt64\bin`. Если не получается — собирайте
из терминала (раздел 2), там Qt Creator не нужен.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `CMakeLists.txt` | описание проекта для CMake: какие файлы собирать и с какой библиотекой Qt |
| `src/main.cpp` | создаёт приложение Qt и показывает окно |
| `src/Calculator.h` | объявление класса окна калькулятора |
| `src/Calculator.cpp` | создание кнопок, раскладки, стили qss, вся логика вычислений |

## Где что сделано

| Требование задания | Как сделано |
| --- | --- |
| режим задаётся радиокнопками, по умолчанию обычный | `QRadioButton` «Обычный» и «Инженерный», `m_normalRadio->setChecked(true)` |
| интерфейс перестраивается, меняется ширина окна | `setEngineeringMode`: инженерная панель прячется или показывается, а `setSizeConstraint(QLayout::SetFixedSize)` подгоняет размер окна под содержимое |
| режим в заголовке в скобках | `setWindowTitle("Калькулятор (обычный)")` / `"Калькулятор (инженерный)"` |
| дисплей — `QPlainTextEdit` с моноширинным шрифтом | `QFont("Consolas")` + `setStyleHint(QFont::Monospace)` |
| интерфейс в коде, без Qt Designer | все виджеты создаются в конструкторе `Calculator` |
| выравнивание — менеджерами размещения | `QVBoxLayout`, `QHBoxLayout`, `QGridLayout` |
| стили qss | строка `STYLE_SHEET` в `Calculator.cpp`, у кнопок свойство `kind` для разного оформления |

## Как считает калькулятор

- Операции выполняются по порядку, как на обычном калькуляторе: `2 + 3 * 4 =` даёт `20`.
- Тригонометрия — в радианах: `π / 2 = sin` даёт `1`.
- `xʸ`: набрать x, нажать `xʸ`, набрать y, нажать `=`. Например, `2 xʸ 10 =` → `1024`.
- `ʸ√x`: набрать x, нажать `ʸ√x`, набрать y, нажать `=`. Например, `27 ʸ√x 3 =` → `3`.
- `n!` — только для целых чисел от 0 до 170: дальше результат не помещается в `double`.
- Деление на ноль, корень из отрицательного числа, логарифм нуля и т.п. показывают «Ошибка».
  После этого можно сразу набирать новое число.
