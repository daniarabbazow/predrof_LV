# Домашнее задание № 1. Потоки ввода-вывода и STL

Курс «Основы программирования на C++». Вариант 1:

- **часть 1, задание 1** — прибавить к каждому числу корень квадратный из произведения
  максимума и последнего числа;
- **часть 2, задание 21** — счёт в банке (номер, код, фамилия владельца, сумма,
  дата открытия, годовой процент), поиск по номеру, коду и владельцу.

## Сборка и запуск

Windows, в терминале в этой папке:

```
g++ -std=c++11 -o homework1 src/main.cpp src/Part1.cpp src/Part2.cpp
.\homework1.exe
```

Linux: `make`, затем `./homework1`.

Программе не нужны аргументы — всё делается через меню. Файлы с данными
(`input.txt`, `output.txt`, `accounts.bin` и другие) создаются в текущей папке.

Фамилии при вводе пишите латиницей: консоль Windows не всегда правильно читает кириллицу.

## Часть 1: где что сделано

| Требование | Функция |
| --- | --- |
| `createData` через файловые потоки | `createDataStream` |
| `createData` через `generate` + `copy` и потоковый итератор | `createDataGenerate` |
| шаблонная `loadData` через файловые потоки | `loadDataStream<Container>` |
| шаблонная `loadData` через потоковые итераторы и `copy` | `loadDataCopy<Container>` |
| `modify` — шаблонная, принимает контейнер, добавляет сумму и среднее по модулю | `modify(const Container&)` |
| `modify` с аргументами-итераторами | `modify(Iter, Iter)` |
| `modify` через `for_each` и лямбду | `modifyForEach` |
| `modify` через `transform` и потоковые итераторы (файл → файл) | `modifyTransform<T>` |
| `outputResult` через файловые потоки | `outputResultStream` |
| `outputResult` через `copy` и потоковый итератор | `outputResultCopy` |
| контейнеры: вектор, двусторонняя очередь, список | меню: пункты 3, 4, 5 (`std::vector`, `std::deque`, `std::list`) |

Шаблонные функции не привязаны к конкретному типу: тип элементов берётся из
`Container::value_type` или `std::iterator_traits<Iter>::value_type`.

**Про корень.** Произведение максимума и последнего числа может быть отрицательным
(если последнее число отрицательное), а корень из отрицательного числа не определён.
Поэтому берётся корень из модуля произведения: `sqrt(|max * last|)`.

**Про сумму и среднее.** Они считаются по модулю для уже изменённых чисел
и дописываются в конец результата: после 100 чисел идут сумма и среднее.

## Часть 2: где что сделано

| Требование | Функция |
| --- | --- |
| запись целиком в бинарный файл | `writeAccount` / `readAccount` (`write` / `read` всей структуры) |
| ввод с клавиатуры и дозапись в файл | `inputAccount`, `addAccounts` |
| удаление записи перезаписью в новый файл | `deleteAccount` |
| замена записи перезаписью в новый файл | `replaceAccount` |
| индексный массив — ассоциативный контейнер | `buildIndex` → `std::multimap<ключ, номер записи>` |
| поиск по номеру, коду, владельцу | `buildNumberIndex`, `buildCodeIndex`, `buildOwnerIndex` + `searchAccounts` |
| найденные записи сохраняются в новый файл | `searchAccounts` → `search_result.bin` |
| ведомость с итогами в текстовом файле | `makeReport` → `report.txt` |

Фамилия хранится в массиве `char[32]`, а не в `std::string`: `std::string` хранит текст
в отдельной памяти, и при записи структуры целиком в файл попал бы только адрес, а не сам текст.
